## ⚡ Comandos de Desenvolvimento e Build

```bash
# Instalação limpa de dependências
npm install

# Servidor de desenvolvimento com HMR
npm run dev

# Análise de qualidade de código (Rust linter com 0 erros/warnings)
npm run lint

# Compilação de produção com code-splitting manual para Three.js (gerado em /dist)
npm run build

# Pré-visualização local do bundle de produção
npm run preview
```
