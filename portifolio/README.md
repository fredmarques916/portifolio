# Aplicação Portfólio — Frederico Marques

Aplicação React + Vite do portfólio profissional de **Frederico Marques**.

Para a documentação completa do projeto, visão geral de arquitetura, narrativa dos projetos e guia de publicação no Render, consulte o [README principal do repositório](../README.md).

## 🚀 Comandos Rápidos

```bash
# Instalação de dependências
npm install

# Servidor de desenvolvimento
npm run dev

# Verificação com Oxlint
npm run lint

# Build de produção (saída em dist/)
npm run build

# Pré-visualização da build
npm run preview
```

## ⚙️ Parâmetros de Publicação no Render (Static Site)

- **Root Directory:** `portifolio`
- **Build Command:** `npm ci && npm run build`
- **Publish Directory:** `dist`
